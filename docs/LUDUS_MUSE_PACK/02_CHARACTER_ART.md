# Character Art Bible — Professor D

## Locked character design (consistent in all scenes)
Visual style: **cinematic painterly semi-realistic 2D character art** with a subtle 2.5D depth treatment. Original character; mature high-end animation aesthetic, not juvenile, clip-art, flat simple SVG or direct imitation of any third-party franchise.
- Male educator, apparent age ~40–43.
- Strong square jaw and prominent cheekbones; light-to-medium olive complexion.
- Realistic amber-gold eyes, intelligent and attentive.
- Dark black hair with restrained salt-and-pepper accents; 1920s-inspired hard-part comb-over, tidy and refined.
- Short, meticulously groomed beard.
- Broad shoulders, athletic lean-muscular physique, confident but welcoming posture.
- Fitted charcoal tailored vest with bronze accents; sophisticated shirt/trousers/boots, cloth/leather detail. Signature bronze educational crest combining gladius, pen, shield and book without visually cluttering the silhouette.
- Personality in expression: perceptive, dignified, warm, humorous when suitable, never threatening or smug.
- Title/personality: Scholar-Commander / Doctore. LUDUS is the academy brand, Professor D the instructor.

## Required assets
1. Canonical master **front full-body portrait** in neutral pose; face/garments clear, full body unclipped.
2. Three-quarter and side silhouettes consistent with master (for walking/turning).
3. Reference sheet: face angles, color palette, crest detail, proportions, materials and lighting.
4. Expressive states: neutral, welcome, explanation, listen, puzzled/thinking, encouragement, verified success.
5. Layered transparent assets or sprite atlas with tested anchors/bounds. Art export should not have arbitrary background baked into the character.
6. Classroom/background assets separate from interactive controls and HTML text.

## Image workflow
- First inspect current code and any existing user-approved image. If no approved image exists, create a **proposed** master from the bible; request founder sign-off before mass-producing derivative poses.
- Prefer official Meta image model *only when entitlement/credit safety and pricing are verified*. Generated images may be inconsistent; check face, eyes, hair, outfit, crest, anatomy across each iteration. Reject and regenerate bad outputs only within approved budget.
- Maintain one source-of-truth character image/ID and color references; document prompt, parameters, rights, and asset provenance. Do not make different unrelated Professor D faces scene-to-scene.
- If segmentation/mask model available, use it for cutout/layer extraction, with alpha edge inspection; segmentation does not animate the object.
- Keep actual UI copy selectable/accessible HTML, not distorted words painted into generated backgrounds.
- Focus on legible face at typical desktop size and strong silhouette for animated states.

## Environment art bible
- Premium original LUDUS Academy: antique scholarly/Roman cues, arches, carved stone, walnut woods, metal and leather, warm bronze, subdued teal/navy lighting, tasteful magical/futuristic teaching surfaces. Warm/human, not dark hostile.
- Strong composition: a clear stage for Professor D and a dominant interactive teaching wall, reliable contrast, layered parallax depth, foreground props that serve learning, physically consistent perspective, lighting/shadows.
- Sub-scenes can change worlds (castle fortification, sky/water cycle, savanna ecology, fractions) while retaining recognizable LUDUS visual language.
